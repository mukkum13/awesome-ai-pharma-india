# Contributing to Awesome AI × Pharma × India

Thank you for considering contributing! 🎉

## How to Contribute

1. **Fork** this repository
2. **Add your resource** to the appropriate section in `README.md`
3. Follow the existing table format
4. **Submit a Pull Request**

## Guidelines

- Only add resources that are genuinely useful for AI in Pharma/Healthcare
- Prefer open-source tools and free resources
- Include a brief, accurate description
- Verify links are working before submitting

## Resource Format

```
| [Tool Name](link) | Brief description | Organization |
|---|---|---|
```

## What to Add

✅ Open-source tools, datasets, research papers, courses, startups
✅ India-specific pharma-tech resources
✅ Free or freemium AI tools for drug discovery/clinical/NLP

❌ Paid-only tools with no free tier
❌ Inactive or deprecated projects
❌ Duplicate entries

## Code of Conduct

Be respectful and constructive. All contributions welcome! 🙏
