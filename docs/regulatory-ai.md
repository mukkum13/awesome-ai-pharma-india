## 🤖 AI for Regulatory Submissions

| Use Case | Tool / Approach |
|---|---|
| Regulatory document classification | Fine-tuned BERT on eCTD documents |
| Adverse event detection | NLP on FAERS/VigiBase data |
| Label extraction & comparison | LLM-based document Q&A |
| Submission gap analysis | GPT-4 / Claude for regulatory review |
| PSUR/PBRER automation | LLM summarization of safety data |
